# sampeinado.github.io

Personal website, built with Jekyll and hosted on GitHub Pages at https://sampeinado.github.io.

## Editing

- **Name, social links:** `_config.yml`
- **Homepage copy:** `index.html`
- **About page:** `about/index.html`
- **Work page (résumé):** `_data/work.yml`
- **Styles:** `assets/css/style.css`

Push to `main` and GitHub Pages rebuilds the site in about a minute.
